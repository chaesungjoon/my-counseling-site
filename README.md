# Mindful Path Counseling

Mindful Path Counseling is a fictional counseling website created as a team project for an AI-assisted coding assignment. The website introduces counseling services and fictional counselor profiles while providing mental-health resources and several interactive features.

## Features

- Five connected HTML pages
- Six counseling service descriptions
- Three fictional counselor profiles
- Appointment request form with validation
- Dark and light themes
- Expandable FAQs
- Guided breathing exercise
- Responsive desktop and mobile layouts
